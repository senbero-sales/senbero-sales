# 開業準備ノート

飲食店の新規開業準備をタスクで管理するPWA（スマホ向け）です。ビルド不要の静的ファイルだけで動き、GitHub Pagesで公開できます。

## 主な機能

- 複数店舗の管理（ヘッダーで切り替え）
- 8カテゴリのチェックリスト：物件・内装／厨房機器／許認可／仕入れ／メニュー・原価／採用・研修／販促／試運転
- タスクごとに期限・担当者・メモを設定
  - 期限は「オープンの○日前」（オープン日から自動で逆算）、「日付を指定」、「なし」から選択
  - オープン日を変更すると、逆算の期限はすべて自動で更新
- ホーム画面に全体とカテゴリ別の進捗率、期限切れ・7日以内のタスクを表示
- 開業準備の一般的なタスク64件をテンプレートとして収録（`templates.js`）
- データはブラウザ（localStorage）に保存。設定画面からJSONで書き出し・読み込み
- オフラインで動作し、ホーム画面に追加可能

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `style.css` | デザイン（ダークモード対応） |
| `app.js` | アプリ本体 |
| `templates.js` | タスクのテンプレート（編集すると新規店舗に反映） |
| `manifest.webmanifest` / `sw.js` / `icons/` | PWA関連 |

## 公開手順（GitHub Pages）

1. このブランチを `main` にマージする
2. リポジトリの Settings → Pages で「Deploy from a branch」、`main` ／ `/ (root)` を選択

ファイルを更新したときは、利用者の端末で新しいファイルが使われるように `sw.js` の `CACHE` の番号を上げてください。

## 注意

- 許認可などの期限はあくまで目安です。届出の期限は自治体・管轄によって異なるため、必ず確認してください。
- データは端末のブラウザ内だけに保存されます。定期的にJSONで書き出してバックアップしてください。
